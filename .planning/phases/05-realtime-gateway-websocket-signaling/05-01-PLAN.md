<objective>
Implement the dedicated Node.js Real-Time Gateway microservice for WebSocket signaling, in-call chat relay, and call status broadcasting, bridged to the FastAPI backend via Redis Pub/Sub.

Purpose: Isolate high-concurrency, long-lived socket connections from the request-response transactional core backend, ensuring resilient real-time teleconsultation signaling and chat relay.
Output: Production-ready Node.js/TypeScript real-time service, JWT handshake verifier, Redis Pub/Sub adapter, WebRTC signaling gateway, and socket integration tests.
</objective>

  <files>realtime-gateway/src/gateways/teleconsultation.gateway.ts, realtime-gateway/src/services/room_manager.ts</files>
  <action>
    Implement Teleconsultation WebSocket Gateway:
    - Room namespace: `/teleconsultation`.
    - Event `join_room`: joins socket room `appointment:{appointment_id}` (verifies user is the assigned doctor or patient).
    - Event `signal_message`: relays WebRTC signaling payload (SDP offer/answer, ICE candidate) to peer in the room.
    - Event `chat_message`: relays in-call text message to peer and pushes copy to Redis queue for FastAPI persistence.
    - Event `call_status`: broadcasts `waiting`, `connected`, `ended` transitions.
  </action>
