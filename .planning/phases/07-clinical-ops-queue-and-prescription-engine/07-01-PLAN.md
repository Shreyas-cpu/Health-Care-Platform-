<objective>
Build the doctor's daily clinical queue dashboard, the structured digital prescription engine with static drug autocomplete, Celery asynchronous PDF generation, and patient health record retrieval—strictly enforcing the Telemedicine Restricted Drug compliance flag.

Purpose: Medical consultations culminate in clinical actions and prescriptions. Providers need frictionless queue management and structured prescribing, while patients need permanent, downloadable medical records.
Output: Clinical queue APIs, prescription authoring endpoints, Celery PDF compiler, patient health record views, and automated compliance tests.
</objective>

<tasks>
<task type="queue">
  <files>backend/app/schemas/queue.py, backend/app/services/queue_service.py, backend/app/api/v1/doctor_queue.py</files>
  <action>
    1. Implement `GET /api/v1/doctor/queue?date=YYYY-MM-DD`:
       - Returns ordered list of day's appointments (both in-person and video) with patient name, mode, time slot, and live status.
    2. Implement queue actions:
       - `POST /api/v1/doctor/queue/{appointment_id}/mark-complete`: transitions appointment to `completed`.
       - `POST /api/v1/doctor/queue/{appointment_id}/mark-no-show`: transitions appointment to `no_show`.
  </action>
  <verify>pytest backend/tests/test_prescription_compliance.py -k "test_queue" || true</verify>
</task>

<task type="prescription">
  <files>backend/app/models/prescription.py, backend/app/models/drug.py, backend/app/services/prescription_service.py, backend/app/api/v1/prescriptions.py</files>
  <action>
    1. Define `DrugMaster` model (id, brand_name, generic_name, dosage_form, is_telemedicine_restricted). Seed with static Indian drug list (e.g. Paracetamol, Amoxicillin, Pantoprazole, etc.).
    2. Define `Prescription` and `PrescriptionItem` models:
       - Prescription: id, appointment_id, doctor_id, patient_id, diagnosis, clinical_notes, pdf_s3_key, issued_at
       - PrescriptionItem: id, prescription_id, drug_name, dosage, frequency (e.g., '1-0-1'), duration_days, instructions (e.g., 'After food')
    3. Compliance Gating Check (CMP-01):
       - If `appointment.mode == 'video'` and any prescribed medication has `is_telemedicine_restricted == True`, reject submission with HTTP 422 ("Medication is restricted for remote teleconsultation under Indian Telemedicine Practice Guidelines").
       - Configurable via admin/database without requiring application code rebuilds.
    4. Implement `POST /api/v1/prescriptions/` (validates appointment is `completed`, saves record, enqueues Celery PDF task).
  </action>
  <verify>pytest backend/tests/test_prescription_compliance.py -k "test_restricted_drug"</verify>
</task>

<task type="worker">
  <files>backend/app/services/pdf_compiler.py, backend/app/workers/tasks.py</files>
  <action>
    1. Implement PDF generator using ReportLab / WeasyPrint:
       - Headers: Doctor name, qualifications, reg number, clinic name and address.
       - Body: Patient name, age/gender, date, diagnosis, structured Rx medication table.
       - Footer: Digital verification stamp and disclaimer per Telemedicine Practice Guidelines.
    2. Celery task `generate_prescription_pdf(prescription_id)`:
       - Generates PDF, uploads to S3 (`prescriptions/{id}.pdf`), and updates `pdf_s3_key` in database.
  </action>
  <verify>pytest backend/tests/test_prescription_compliance.py -k "test_pdf" || true</verify>
</task>
